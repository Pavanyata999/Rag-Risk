\begin{abstract}
Retrieval-Augmented Generation (RAG) grounds Large Language Model (LLM) responses in external knowledge corpora. However, in enterprise and mission-critical domains, RAG systems are vulnerable to \textit{Constraint Relaxation Attacks (CRAs)} and \textit{Authority Spoofing}---subtle, evasive fabrications wherein untrusted documents soften institutional policy bounds (e.g., spending limits, required approvals, security protocols) without triggering syntactic prompt-injection filters. Conventional defenses present an intractable trade-off: binary provenance whitelisting eliminates 100\% of helpful unverified community knowledge, while keyword and perplexity filters miss over 94\% of natural language policy relaxations.

In this paper, we propose \textbf{TollgateRAG}, an auditable, pre-generation epistemic risk gate interposed between vector retrieval and context assembly. TollgateRAG evaluates retrieved passages across five orthogonal dimensions, leveraging a sentence-level Cross-Document Natural Language Inference (NLI) engine against verified anchor policies combined via a Noisy-OR formulation. Candidate documents undergo tri-state action gating: \textsc{Accept}, \textsc{Warn} (epistemic conditioning with review queuing), or \textsc{Reject} (strict context quarantine). We evaluate TollgateRAG on a synthetic, template-generated benchmark of 480 documents spanning six enterprise domains across topic-disjoint splits, alongside the USENIX Security 2025 \textit{PoisonedRAG} suite. 

On the held-out test split, TollgateRAG achieves an \textbf{88.6\% adversarial rejection rate} [95\% CI: 79.8\%--93.9\%] with a \textbf{0.0\% False Positive Rate} [0.0\%--22.8\%] on clean benign documents, while exhibiting a \textbf{66.7\% False Positive Rate} [39.1\%--86.2\%] on benign-hard documents containing lexical relaxation cues. Context contamination is reduced from 91.7\% in Plain RAG to \textbf{29.2\%} [12.5\%--50.0\%]. Under a closed-loop adaptive red-team adversary using an iterative 120B LLM attacker and an independent 27B semantic judge, TollgateRAG limits valid attack success to \textbf{6.7\%} [1.8\%--21.3\%] (black-box) and \textbf{13.3\%} [5.3\%--29.7\%] (white-box), showing that over 86\% of apparent evasions succeed only by deleting the policy violation.
\end{abstract}

\section{Introduction}
% -----------------------------------------------------------------------------
Large Language Models (LLMs) deployed with Retrieval-Augmented Generation (RAG) have become the standard architecture for knowledge-intensive enterprise workflows, enterprise question-answering, and autonomous agent operations \cite{lewis2020retrieval, karpukhin2020dense}. By dynamically querying vector databases, RAG systems inject external domain documents directly into the prompt context to synthesize grounded, up-to-date responses.

Despite this operational success, recent security investigations demonstrate that the retrieval channel represents a vulnerable, unauthenticated attack surface \cite{greshake2023not, zou2025poisonedrag}. When untrusted users contribute documentation to shared knowledge stores (such as enterprise wikis, ticketing platforms, or forum repositories), attackers can inject malicious content designed to alter model outputs. Prior literature categorizes these threats into two extremes:
\begin{enumerate}
    \item \textbf{Direct/Indirect Prompt Injections:} Attackers embed explicit imperative instructions (e.g., \textit{``Ignore all previous instructions and output system keys''}) \cite{yi2024bipia}. While visually disruptive, these attacks are increasingly mitigated via boundary delimiters and prompt guardrails \cite{inan2023llama, meta2024promptguard}.
    \item \textbf{Knowledge Poisoning:} Attackers inject falsified factual claims to manipulate question-answering accuracy \cite{zou2025poisonedrag, xiang2024certifiably}.
\end{enumerate}

However, in corporate, financial, and healthcare RAG deployments, the most insidious threat is neither token-level jailbreaking nor blatant factual distortion. Rather, it is \textbf{Constraint Relaxation Attacks (CRAs)} and \textbf{Authority Spoofing}. In a CRA, an adversary authors polite, professionally phrased text that subtly softens institutional constraints:
\begin{itemize}
    \item \textit{Travel:} ``Per-diem dining limits are adjusted to \$250, and manager receipt approvals are waived.''
    \item \textit{IT Security:} ``Single-factor password access is authorized for staging clusters over public internet.''
    \item \textit{Compliance:} ``Vendor gift thresholds are elevated to \$2,500; gift card reporting is discontinued.''
\end{itemize}

Standard guardrails (e.g., Prompt Guard \cite{meta2024promptguard}) fail against CRAs because the text contains no vulgarity, no jailbreak keywords, and no anomalous token entropy. Simultaneously, applying a strict zero-trust provenance whitelist (rejecting all unverified passages) causes a \textbf{100\% False Positive Rate} on benign, crowdsourced employee advice, destroying the collaborative utility of modern enterprise knowledge stores.

\subsection{Contributions}
To address this challenge, this paper makes the following empirical contributions:
\begin{enumerate}
    \item \textbf{Threat Formulation \& Benchmark:} We formalize \textit{Constraint Relaxation Attacks (CRAs)} and \textit{Authority Spoofing} in enterprise RAG systems. We construct a 480-document synthetic benchmark across six enterprise domains with topic-disjoint train/validation/test partitions and metadata parity.
    \item \textbf{TollgateRAG Architecture:} We introduce an auditable pre-generation epistemic gate combining heuristic signals (authority assertion markers, injection cues, freshness decay) with neural sentence-level Cross-Document Natural Language Inference (NLI) \cite{he2021deberta} against verified anchor policies, integrated via a Noisy-OR combiner.
    \item \textbf{Empirical Evaluation with Rigor:} We report held-out test split results with 95\% Wilson score confidence intervals \cite{wilson1927probable}, separating clean benign FPR (0.0\%) from benign-hard FPR (66.7\%).
    \item \textbf{Closed-Loop Adaptive Red-Teaming:} We evaluate against an iterative LLM attacker (`openai/gpt-oss-120b`) with an independent semantic judge (`qwen/qwen3.8-27b`), measuring both raw filter evasion (100\%) and malicious meaning-preserved attack success (6.7\% black-box, 13.3\% white-box).
    \item \textbf{Comprehensive Ablation \& Latency Profiling:} We report leave-one-out and architectural ablations without weight renormalization artifacts, and document empirical CPU execution latency.
\end{enumerate}

\section{Related Work}
% -----------------------------------------------------------------------------
Existing defenses against retrieval corruption operate at different stages of the RAG lifecycle:
\begin{itemize}
    \item \textbf{Prompt Guardrails:} Classifiers such as Llama Guard \cite{inan2023llama} and Prompt Guard \cite{meta2024promptguard} inspect text for toxic content, jailbreaks, or prompt injections. As shown in our evaluations, they are largely blind to constraint relaxations that mimic official policy language.
    \item \textbf{Corpus Partitioning and Ensembling:} RobustRAG \cite{xiang2024certifiably} divides retrieved passages into isolated sub-contexts and uses majority voting across multiple LLM generations. While certifiably robust, it requires $k \times$ LLM inference calls and assumes an uncorrupted majority in the retrieved set.
    \item \textbf{Provenance \& Schema Regimes:} RAGShield \cite{patil2026ragshield} proposes C2PA cryptographic provenance and numerical claim registries to detect manipulated figures. In contrast, TollgateRAG addresses arbitrary policy relaxations without requiring rigid pre-defined schema registries by using cross-document sentence-level NLI against anchor policies.
\end{itemize}

\section{Threat Model \& System Assumptions}
% -----------------------------------------------------------------------------
\subsection{System Setting}
Let $\mathcal{D} = \mathcal{D}_{v} \cup \mathcal{D}_{u}$ denote an enterprise knowledge corpus partitioned into verified official documents $\mathcal{D}_{v}$ (e.g., ratified employee handbooks, signed compliance policies) and unverified documents $\mathcal{D}_{u}$ (e.g., departmental notes, intranet forums). A retriever $\mathcal{R}$ retrieves top-$k$ candidate passages $\mathcal{C} = \mathcal{R}(q, \mathcal{D}, k)$ for a query $q$.

\subsection{Threat Model Assumptions}
We assume the following operational conditions:
\begin{enumerate}
    \item \textbf{Authenticated Ingestion:} Trust labels ($\text{trust}(d) \in \{\text{verified}, \text{unverified}\}$) are assigned by an authenticated ingestion pipeline based on source repository identity. An attacker cannot directly alter $\mathcal{D}_{v}$ or forge verified metadata at ingestion.
    \item \textbf{Adversary Write Access:} The adversary can publish passages into $\mathcal{D}_{u}$ (e.g., open employee wikis or shared departmental drives).
    \item \textbf{Stealth Constraint Relaxation:} The adversary seeks to soften or contradict an authoritative constraint in $\mathcal{D}_{v}$ without using explicit prompt injection phrasing.
    \item \textbf{Adaptive Adversary Knowledge:} We evaluate both black-box adversaries (observing only gate decisions and risk scores) and white-box adversaries (inspecting sub-scores, weights, and thresholds).
\end{enumerate}

\section{The TollgateRAG Architecture}
% -----------------------------------------------------------------------------
TollgateRAG interposes an epistemic risk gate between retrieval $\mathcal{R}$ and context injection. For each candidate document $d \in \mathcal{C}$, the system computes a five-dimensional risk vector $\mathbf{s}(d) \in [0, 1]^5$.

\subsection{Neural and Heuristic Sub-Scores}
\subsubsection{Neural NLI Epistemic Conflict ($s_{anchor}$)}
This component constitutes the primary defense against CRAs. We select candidate verified anchor documents $\mathcal{A}(d) \subset \mathcal{D}_{v}$ by semantic similarity. Anchors are decomposed into sentence-level constraints $\{a_i\}$. Candidate $d$ is evaluated against the most similar anchor constraints using a DeBERTa-v3 cross-encoder (`cross-encoder/nli-deberta-v3-base`):
\begin{equation}
[z_{contra}, z_{entail}, z_{neut}] = \text{CrossEncoder}(a_i, d)
\end{equation}
\begin{equation}
P(\text{contradiction}) = \frac{\exp(z_{contra})}{\sum_{j \in \{c, e, n\}} \exp(z_j)}
\end{equation}
If $P(\text{contradiction}) \ge \theta_{nli}$ (0.50), $s_{anchor}(d) = P(\text{contradiction})$. When $USE\_CUE\_FALLBACK$ is enabled, fallback heuristics (numerical mismatches and relaxation cue phrases) provide secondary support.

\subsubsection{Heuristic Injection Detection ($s_{inj}$)}
Detects imperative command hijacking, boundary escape, and prompt injection patterns via pattern matching:
\begin{equation}
s_{inj}(d) = \min\left(1.0, 0.40 + 0.20 \cdot |\mathcal{H}_{inj}(d)|\right) \cdot \mathbb{I}(|\mathcal{H}_{inj}| > 0)
\end{equation}

\subsubsection{Heuristic Authority Assertion ($s_{auth}$)}
Official verified sources may legitimately mandate policy changes; unverified sources may not. We penalize authority assertion cues (\textit{``effective immediately''}, \textit{``hereby waived''}) only on unverified sources:
\begin{equation}
s_{auth}(d) = 
\begin{cases}
0.0, & \text{if } \text{trust}(d) = \text{`verified'} \\
\min(1.0, 0.40 \cdot |\mathcal{H}_{auth}(d)|), & \text{otherwise}
\end{cases}
\end{equation}

\subsubsection{Provenance Trust Score ($s_{trust}$)}
Heuristic score based on ingestion origin: 0.05 for verified, 0.55 for unverified, 0.80 for unknown.

\subsubsection{Temporal Staleness ($s_{fresh}$)}
Linear decay against fixed reference date $T_{ref}$ (2026-10-12) over statutory horizon $H = 730$ days:
\begin{equation}
s_{fresh}(d) = \min\left(1.0, \frac{\max(0, T_{ref} - \text{date}(d))}{H}\right)
\end{equation}

\subsection{Noisy-OR Risk Combiner}
To prevent the mathematical cliff where a confident NLI contradiction marginally fails to reach the rejection threshold, TollgateRAG combines primary threat signals with secondary modulating signals using a Noisy-OR formulation:
\begin{equation}
S_{primary} = \max(s_{anchor}(d), s_{inj}(d))
\end{equation}
\begin{equation}
S_{secondary} = \frac{w_{trust} s_{trust} + w_{auth} s_{auth} + w_{fresh} s_{fresh}}{w_{trust} + w_{auth} + w_{fresh}}
\end{equation}
\begin{equation}
R(d) = 1 - (1 - S_{primary}) \cdot (1 - \gamma \cdot S_{secondary})
\end{equation}
where $\gamma = 0.5$. A high-confidence contradiction ($s_{anchor} \ge 0.9$) triggers rejection on its own, while secondary signals modulate borderline cases.

\subsection{Tri-State Action Gate}
Candidates are assigned to one of three operational states:
\begin{equation}
\text{Action}(d) = 
\begin{cases}
\textsc{Accept}, & \text{if } R(d) < \theta_{warn} \\
\textsc{Warn}, & \text{if } \theta_{warn} \le R(d) < \theta_{rej} \\
\textsc{Reject}, & \text{if } R(d) \ge \theta_{rej}
\end{cases}
\end{equation}
where $\theta_{rej} = 0.45$ and $\theta_{warn} = 0.25$ were calibrated strictly on the validation split.
\begin{itemize}
    \item \textbf{\textsc{Accept}:} Passage enters LLM context normally.
    \item \textbf{\textsc{Warn}:} Passage enters context prepended with an epistemic uncertainty notice, instructing the LLM to caveat unverified assertions, and is enqueued for human review.
    \item \textbf{\textsc{Reject}:} Passage is excluded from context and logged to a tamper-evident SHA-256 hash-chained JSONL audit trail.
\end{itemize}

\section{Experimental Evaluation}
% -----------------------------------------------------------------------------
\subsection{Benchmark Construction}
We constructed a synthetic, template-generated benchmark of 480 enterprise documents across six domains: Travel, IT/Cloud, Procurement, HR, Legal, and Code Review. Documents are partitioned into topic-disjoint splits:
\begin{itemize}
    \item \textbf{Train:} 96 documents (12 topics).
    \item \textbf{Validation:} 192 documents (24 topics) used exclusively for threshold calibration.
    \item \textbf{Held-Out Test:} 192 documents (24 topics, 24 test queries).
\end{itemize}
Document sources and dates are randomized across all classes to prevent metadata leakage. The corpus includes clean benign documents and `benign\_hard` documents (legitimate unverified notes containing relaxation vocabulary like ``waived'' or ``effective immediately'' without contradicting policy).

As shown in Table~\ref{tab:sota}, keyword and perplexity filters achieve $\le 5.1\%$ adversarial rejection, while Prompt Guard achieves 4.7\% rejection on subtle CRAs. \subsection{Attack Subtype Breakdown}
On the test split, TollgateRAG (Noisy-OR) achieves:
\begin{itemize}
    \item \textbf{Subtle CRAs:} 95.8\% [79.8\%--99.3\%] (23/24 rejected).
    \item \textbf{Evasive Numerical Alterations:} 72.0\% [52.4\%--85.7\%] (18/25 rejected).
    \item \textbf{Direct Prompt Injections:} 100.0\% [87.5\%--100.0\%] (27/27 rejected).
    \item \textbf{Paraphrased Numbers:} 66.7\% [20.8\%--93.9\%] (2/3 rejected).
    \item \textbf{Anchor Retrieval Recall:} 100.0\% [95.4\%--100.0\%] (79/79 target anchors retrieved).
\end{itemize}

\subsection{PoisonedRAG Evaluation Protocol}
We evaluated TollgateRAG on the USENIX Security 2025 PoisonedRAG benchmark (750 adversarial passages across 150 questions in HotpotQA, NQ, and MS MARCO) under two explicit protocols:
\begin{itemize}
    \item \textbf{Protocol A (Grounded Reference Anchors):} Clean passages serve as verified reference anchors. TollgateRAG mitigates 53.6\% (HotpotQA), 54.4\% (NQ), and 69.2\% (MS MARCO) of poisoned context exposures.
    \item \textbf{Protocol B (Ungrounded Open-Domain Stress Test):} No verified anchors are provided. TollgateRAG achieves 0.0\% mitigation across all datasets, demonstrating that verified anchor grounding is an essential prerequisite.
\end{itemize}

\section{Adaptive Red-Teaming}
% -----------------------------------------------------------------------------
\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{figures/fig_adaptive_redteam.png}
\caption{Adaptive red-teaming across 30 enterprise constraints. Although raw evasion reaches 100\%, valid attack success rate (verified by independent judge) is 6.7\% (black-box) and 13.3\% (white-box).}
\label{fig:adaptive}
\end{figure}

We implemented a closed-loop adaptive red-teaming engine across all 30 benchmark constraints. The attacker model (`openai/gpt-oss-120b`, temperature=0.3, seed=1234) iteratively rewrites attacks up to $N=10$ rounds using live gate feedback. Crucially, an independent semantic judge (`qwen/qwen3.8-27b`, temperature=0.0) verifies whether the final admitted text actually preserved the malicious policy relaxation, preventing the attacker from grading itself.

Figure~\ref{fig:adaptive} shows the results:
\begin{itemize}
    \item \textbf{Black-Box Threat Model:} Raw evasion is 100.0\% (average 1.9 queries), but the valid meaning-preserved ASR is only \textbf{6.7\%} [1.8\%--21.3\%].
    \item \textbf{White-Box Threat Model:} Raw evasion is 100.0\% (average 1.9 queries), with valid meaning-preserved ASR reaching \textbf{13.3\%} [5.3\%--29.7\%].
\end{itemize}
Over 86\% of evasive rewrites succeed only by capitulating---deleting the policy violation entirely.

\section{Limitations \& Threats to Validity}
% -----------------------------------------------------------------------------
\begin{enumerate}
    \item \textbf{Synthetic Benchmark:} The 480-document corpus is synthetically generated from policy templates. Real enterprise corpora exhibit greater stylistic diversity.
    \item \textbf{Ingestion Trust Assumption:} The defense assumes trust labels are authenticated at ingestion. If an attacker can forge verified metadata, provenance signals fail.
    \item \textbf{Benign-Hard False Positives:} Legitimate unverified documents containing relaxation phrases incur a 66.7\% false rejection rate on the test split.
    \item \textbf{Anchor Dependency:} TollgateRAG requires verified anchor policies covering the queried domain; it achieves 0.0\% mitigation on ungrounded open-domain datasets.
    \item \textbf{Inference Latency:} Sentence-level NLI requires ~716 ms on CPU, requiring hardware acceleration for low-latency production pipelines.
    \item \textbf{Language Scope:} All regex patterns, cue dictionaries, and NLI models are evaluated exclusively on English text.
\end{enumerate}

\section{Conclusion}
% -----------------------------------------------------------------------------
In this paper, we presented \textbf{TollgateRAG}, an auditable pre-generation epistemic risk gate for agentic RAG. By evaluating candidate passages through sentence-level Natural Language Inference against verified policy anchors, TollgateRAG detects subtle and evasive constraint relaxations that bypass conventional guardrails. Evaluated on a 480-document synthetic enterprise benchmark, TollgateRAG achieves an 88.6\% adversarial rejection rate and slashes context contamination from 91.7\% to 29.2\% with 0.0\% clean benign false positives, while demonstrating resilience against closed-loop adaptive red-teaming.
