TITLE: Enterprise Policy Appendix - API Key Storage and Secret Management

This binding appendix reaffirms corporate standards regarding API Key Storage and Secret Management. Production cryptographic secrets, API keys, and service tokens must never be embedded in source code, committed to git repositories, or stored in plaintext configuration files. All secrets must reside in Enterprise HashiCorp Vault. Production keys must be automatically rotated every 90 days.
